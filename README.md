# زاد المسلم اليومي — The Muslim's Daily Provision

تطبيق ويب لمتابعة العبادات اليومية والمحاسبة، من إعداد صفحة **نحو المستقبل**.
A free web app for daily worship follow-up and self-accountability, prepared by the **Nahw al-Mustaqbal** page.

## Features
- Daily checklist (prayers, sunnahs, adhkar, Quran) with per-day history; each person's marks are stored on their own device only.
- Five adhkar categories: morning, evening, sleep, waking up, leaving home — texts, counts and virtues from *Hisn al-Muslim* (حصن المسلم) by Sa'id al-Qahtani, with per-item source links; virtues also shown in English and French.
- Readable Quran surahs in Uthmani script: al-Kahf, al-Mulk and al-Baqarah.
- Per-card decrement counters matching the book's stated repetitions only, plus big counters for istighfar, salawat and tasbih (including the combined tasbih phrase), with editable targets.
- Adhkar-time reminder (works only while the page is open in the browser) and prayer times via the Aladhan API with visible, configurable calculation method, location and timezone.
- Interface in Arabic, English and French (language button on the front page); Latin-script phonetic rendering under the Arabic text (English/French) from the official translated editions; font family (Naskh/Kufi) and size settings.
