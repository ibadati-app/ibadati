# عباداتي اليومية — My Daily Worship

تطبيق ويب لمتابعة العبادات اليومية والأذكار، من إعداد صفحة **نحو المستقبل**.
A free web app for daily worship tracking and adhkar, prepared by the **Nahw al-Mustaqbal** page.

## Features
- Daily checklist (prayers, sunnahs, adhkar, Quran) with per-day history; each person's marks are stored on their own device only.
- Five adhkar categories: morning, evening, sleep, waking up, leaving home — texts, counts and virtues from *Hisn al-Muslim* (حصن المسلم) by Sa'id al-Qahtani, with per-item source links.
- Per-card decrement counters matching the book's stated repetitions only.
- Interface in Arabic, English and French; Latin-script phonetic rendering under the Arabic text (English/French) from the official translated editions; font family (Naskh/Kufi) and size settings.
